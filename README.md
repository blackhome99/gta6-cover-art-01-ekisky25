Neon Coast Cover Studio — an offline web app that turns any photo + caption into GTA 6-style multi-panel cover art, exported as PNG. Upload a photo (drag/drop), pick a layout (Hero, Duo, Trio, Grid 4, Hero+3, Tilted), grade it (Sunset, Neon, Dusk, Mono, Vice), add role labels, big title, tagline, stars, quote, seal and barcode — your photos never leave the machine.

## Run it

```sh
node serve.ts # then open http://localhost:8080
```
